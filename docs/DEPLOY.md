# Crow Deployment Guide

Crow is a static Next.js 15 export. It can be deployed to any static host or as a Docker container.

## Build

```bash
npm ci
npm run generate:icons
npm run build
```

The static export is written to `dist/`.

## Environment variables

| Variable | Purpose |
|---|---|
| `CROW_BASE_PATH` | Base path for subdirectory deploys (e.g. `/crow`). Defaults to `/`. |
| `NODE_ENV` | Set to `production` for builds. |

## Hosts

### Vercel

Connect the repository to Vercel. `vercel.json` is generated by `scripts/gen-headers.mjs`.

### GitHub Pages

Use `.github/workflows/pages.yml`. Set `CROW_BASE_PATH: /crow`.

### Cloudflare Pages / Netlify

Build command:

```bash
npm ci && npm run generate:icons && npm run build
```

Publish directory: `dist`

`public/_headers` is generated by `scripts/gen-headers.mjs`.

### Render

`render.yaml` is generated by `scripts/gen-headers.mjs`.

### Fly.io

```bash
fly launch --from fly.toml
```

### Railway

Connect the repository. `railway.json` points to the `Dockerfile`.

### Docker

```bash
docker build -t crow .
docker run -p 8080:8080 crow
```

The image uses `nginxinc/nginx-unprivileged` and runs as a non-root user with a read-only root filesystem.

## Header generation

Run `node scripts/gen-headers.mjs` after changing `src/core/util/csp.ts` to update host header files.

Run `node scripts/check-headers.mjs` to validate they are consistent.

## Security notes

- Security headers are enforced by the host config (or nginx.conf for Docker).
- CSP is injected via a `<meta>` tag for static exports.
- For stricter CSP, see the F2 phase in `docs/AUDIT-FIX.md`.
